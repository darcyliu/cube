# Superseded ZFS implementation plan

The original direct-module-boot plan is superseded. Its implementation status
and remaining work are consolidated in [ZFS boot architecture](freebsd_zfs_boot.md#implementation-status).
Use the [UEFI/ZFS regression runbook](freebsd_zfs_runbook.md) for commands and
recorded validation. UEFI is the verified root-on-ZFS path; direct MODINFO boot
remains experimental.

This page preserves existing links; it is not a separate source of status.
